IRONFLOW - APK ANDROID

Este pacote contém o código-fonte do MVP, não um APK já compilado.
A compilação automática é feita pelo GitHub Actions: abra a aba Actions, aguarde Build Android APK e baixe o artefato ironflow-android-apk.

O app demonstrativo usa armazenamento local no dispositivo e não exige conta ou servidor para as funções implementadas.

Limitações: treinos e exercícios são demonstrativos; não há login, sincronização em nuvem, pagamentos ou IA. Teste no aparelho antes de considerar o aplicativo pronto para uso comercial.
