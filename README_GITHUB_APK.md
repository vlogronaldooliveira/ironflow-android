# Como baixar o APK

1. Abra a aba **Actions** deste repositório.
2. Entre na execução mais recente de **Build Android APK**.
3. Quando terminar com sucesso, baixe o artefato **ironflow-android-apk**.
4. Extraia o ZIP e instale `app-debug.apk` no Android. Talvez seja necessário autorizar a instalação desta origem.

O APK é uma compilação de teste (debug), não assinada para distribuição comercial. O GitHub é usado para guardar o código e compilar o instalador; as funções implementadas no app armazenam os dados localmente.
